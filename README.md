# MedicineSimulator MedSim

MedSim — веб-платформа клинической симуляции для студентов медицинских вузов. Студент изучает симптомы виртуального пациента, изображения и 3D-модель, слушает голосовые жалобы, выбирает диагноз и получает результат. Преподаватель управляет упражнениями и отслеживает прогресс через административную панель.

## Возможности

- роли студента и администратора;
- клинические упражнения и история попыток;
- 3D-визуализация виртуального пациента;
- изображения и синтез голосовых жалоб;
- статистика прогресса и ошибок;
- управление упражнениями, диагнозами, симптомами и пользователями;
- интерфейс на русском, казахском и английском языках.

## Технологии

- React, TypeScript, Vite и Tailwind CSS;
- Bun и ElysiaJS;
- PostgreSQL, Prisma ORM;
- Docker Compose;
- Three.js, React Three Fiber и Spline;
- GitHub Actions.

## Локальный запуск

```bash
docker compose up -d

cd backend
cp .env.example .env
bun install
bun run prisma:migrate
bun run db:seed
bun run dev

cd ../webapp
bun install
bun run dev
```

Не добавляйте рабочие `.env` и API-ключи в Git. Значения в `.env.example` предназначены только для документирования структуры конфигурации.
