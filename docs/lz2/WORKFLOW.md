# Рабочий процесс MedSim

## Задачи

Заголовок начинается с типа и описывает проверяемый результат:

```text
[Feature] Добавить предупреждение об учебном назначении
[Bug] Исправить расчет результата попытки
[Clinical] Проверить план лечения острого аппендицита
[Task] Проверить миграции на заполненной базе
```

Каждая задача содержит контекст, критерии приемки, риск, зависимости и необходимость clinical review.

## Ветки

```text
feature/12-educational-disclaimer
fix/18-attempt-score
clinical/23-appendicitis-review
test/27-exercise-flow
docs/31-recovery-runbook
```

## Definition of Ready

- понятна ценность и целевая роль;
- записаны проверяемые критерии приемки;
- определены зависимости, размер, приоритет и риск;
- указано, требуется ли clinical review;
- задача помещается в одну итерацию или разбита.

## Definition of Done

- критерии приемки выполнены;
- typecheck, тесты и сборка проходят;
- основной и отрицательный сценарии проверены;
- миграции и права доступа проверены, если применимо;
- медицинский контент утвержден преподавателем, если применимо;
- pull request связан с issue и рассмотрен другим участником;
- документация обновлена;
- в Git отсутствуют `.env`, API-ключи и персональные данные;
- результат готов к демонстрации.
